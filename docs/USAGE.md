# HELIX usage

## External storage

```sh
export HELIX_DATA_ROOT=/home/user/.helix/data
python scripts/migrate_artifacts.py --check
python -m helix.storage.guard
```

Relative paths in `configs/*.json` resolve below `HELIX_DATA_ROOT`. The
repository contains source, schemas, manifests and documentation only. The
guard blocks training arrays, checkpoints and generated corpora from being
committed.

## Source corpus and smoke experiment

```sh
python -m helix sources
python -m helix train --config configs/helix-source-smoke.json
python -m helix sft --config configs/helix-source-smoke-sft.json \
  --base-checkpoint "$HELIX_DATA_ROOT/artifacts/source-smoke/llm/ckpt-best.pt" \
  --sft-pairs "$HELIX_DATA_ROOT/artifacts/sft-smoke/sft_pairs.json" \
  --out-dir "$HELIX_DATA_ROOT/artifacts/source-smoke/sft" --max-iters 20
python -m helix web --config configs/helix-source-smoke.json \
  --checkpoint "$HELIX_DATA_ROOT/artifacts/source-smoke/sft/sckpt-best.pt" \
  --host 0.0.0.0 --port 8766
```

The initial catalog contains the MIT-licensed HELIX seed corpus. The command
reads it from the repository, copies it into external `raw/` storage without a
network request, filters benchmark names, deduplicates text, writes
deterministic train/validation/test splits with hashes and trains a 512-token
byte-level BPE only on the training split. It does not download third-party
content by default. The two smoke configurations use 155,968 randomly
initialized parameters, 64-token contexts, 30 pretraining iterations and 20
instruction-tuning iterations; they validate the pipeline and artifacts, not
language capability. `artifacts/sft-smoke/sft_pairs.json` is generated by
`helix.sft.build_instruction_pairs` from the deterministic seed text.

## Training and chat

```sh
python -m helix train --config configs/helix-research.json
python -m helix chat --config configs/helix-research.json
python -m helix web --host 0.0.0.0 --port 8766
```

The model is randomly initialized. Start training from a checkpoint with
`--resume`. Separate pretraining and instruction-tuning stages must not be
combined into one reported number.
