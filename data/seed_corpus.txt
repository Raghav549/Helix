== SCIENCE ==
Photosynthesis is the process by which green plants convert sunlight into chemical energy.
Chlorophyll captures photons and drives the electron transport chain in the thylakoid membrane.
Water is split into oxygen, protons, and electrons; carbon dioxide is fixed into glucose.
The overall equation is six carbon dioxide plus six water yields one glucose and six oxygen.
Mitochondria are the powerhouses of the cell, producing ATP through oxidative phosphorylation.
DNA is organized into a double helix; the sequence of bases encodes proteins through the genetic code.
Gravity is the curvature of spacetime caused by mass and energy, as described by general relativity.

== CODE ==
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

== MATH ==
The Pythagorean theorem states that in a right triangle, a squared plus b squared equals c squared.
A prime number is a natural number greater than one that has no positive divisors other than one and itself.
The derivative of a function measures how its output changes as its input changes.
The integral of a function gives the area under its curve.
Euler's identity relates e, i, pi, one, and zero in a single elegant equation.
